# PageTurner - Personal Library & Reading Tracker

A lightweight, responsive personal book library and reading tracker web app built with vanilla HTML, CSS, and JavaScript. All data is saved locally in the browser with `localStorage`.

## Features

- **Add Books**: Add books with Title, Author, Cover Image (URL or file upload with live preview), Description, and Read/Unread status.
- **Reading Progress Bar**: Live progress tracking showing total books, books read, books to read, and percentage completed.
- **Instant Search & Filters**: Search in real-time by title, author, or description. Filter by All, Read, or Unread.
- **Sorting Options**: Sort by newest, oldest, title (A-Z / Z-A), or author.
- **Edit & Delete**: Easily update book details or delete books with confirmation prompts.
- **Light & Dark Mode**: Seamless theme switching with saved preference.
- **Responsive & Mobile First**: Optimized for desktop, tablets, and mobile screens.
- **100% Offline**: No servers, databases, or accounts needed.

## Getting Started

Simply open `index.html` in any modern web browser.
